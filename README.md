# Beyond HYPE 

### *Less hype. More evidence. Clearer next steps.*

---

##  About the Project

**Beyond HYPE** is an interactive technology-industry intelligence platform that helps students understand how the technology industry is changing, which skills matter, and how to prepare for future opportunities.

Technology changes quickly, but students often struggle to connect what they learn in college with the skills, tools, and responsibilities expected in the industry. Beyond HYPE aims to bridge this gap by turning industry evidence into practical learning guidance.
##  Problem Statement

Students often struggle to identify relevant technologies, understand changing industry requirements, and decide which skills to develop during college.

Beyond HYPE aims to address this challenge by providing structured insights into technology trends, evolving professional roles, relevant skills, and practical learning opportunities.

##  Features

- **Explore Technology Fields:** Discover Software Development, Artificial Intelligence, Data, Cybersecurity, and Cloud Computing.
- **Industry Change Analysis:** Understand how technologies, tasks, and professional roles are evolving.
- **Human Capabilities:** Explore the skills and responsibilities that remain important as automation changes workflows.
- **Career Exploration:** Discover established, evolving, and specialized technology roles.
- **Skills and Tools:** Learn about relevant technologies and tools.
- **Learning Roadmaps:** Explore learning paths and practical projects.
- **Evidence-Based Insights:** Examine sources supporting industry-related findings.
- **Hype Check:** Evaluate technology claims against available evidence.
- **Search:** Find roles, technologies, projects, skills, and learning resources.

##  Getting Started

### Prerequisites

- [Python](https://www.python.org/downloads/) 
- [Git](https://git-scm.com/downloads/) — to clone the repository.
- A modern web browser.

### Running the Project

**1. Clone the repository**

 `https://github.com/YashasviYadav81/BeyondHYPE-` 

```bash
git clone https://github.com/YashasviYadav81/BeyondHYPE-
```

**2. Open the project folder**

```bash
cd Beyond_HYPE
```

**3. Install Dependencies**

Install the Python packages listed in `requirements.txt`:

```bash
python -m pip install -r requirements.txt
```

**4. Start the Backend**

The exact startup command must be confirmed from `main.py` and the project's configuration before use.

**5. Open the frontend**

Open `Frontend/index.html` in your code editor or use a local development server.
